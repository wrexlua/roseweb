🔐 Authentication

All protected endpoints require two HTTP headers:

HeaderDescription
X-Auth-TokenRotating hash: SHA256(window:key:secret)[0:16], changes every 30s
X-Auth-TsUNIX timestamp used to generate the token

C++ Token Generator

<string>
#include <openssl/sha.h>
#include <ctime>

std::string sha256_hex(const std::string &in) {
    unsigned char hash[SHA256_DIGEST_LENGTH];
    SHA256((unsigned char*)in.data(), in.size(), hash);
    std::ostringstream out;
    for (int i = 0; i < SHA256_DIGEST_LENGTH; i++)
        out << std::hex << std::setw(2) << std::setfill('0') << (int)hash[i];
    return out.str();
}

std::string gen_token(const std::string &key) {
    long long w = time(nullptr) / 30;
    return sha256_hex(std::to_string(w) + ":" + key + ":rose-api-auth-v2-secret").substr(0, 16);
}

⚠ The API secret (rose-api-auth-v2-secret) is embedded in your C++ loader. Use string obfuscation.
